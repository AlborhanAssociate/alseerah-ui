# السيرة ai — واجهات المنصّة

واجهات الهبوط والدخول والمحادثة لمنصّة «السيرة ai»، مبنيّة بـ Vite وReact 19 وTypeScript وTailwind CSS 3.4 وlucide-react، بالعربيّة واتّجاه RTL، وبنمطَين فاتحٍ وداكن.

## التشغيل

```bash
npm install
npm run dev
```

ثمّ افتح `http://localhost:5173`.

| المسار | الشاشة |
|---|---|
| `/` | الهبوط (شاشة واحدة على نسق البينتو) |
| `/classic` | الهبوط السابق ذو الأقسام، للمقارنة |
| `/login` | الدخول (نموذج محلّيّ مؤقّت) |
| `/chat` | المحادثة (تتطلّب جلسة) |
| `/privacy` و`/terms` | صفحتان قانونيّتان |

## البناء

```bash
npm run build
```
